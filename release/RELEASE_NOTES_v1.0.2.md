# JLABROC/JSRT-MRMC Python 1.0.2

Version 1.0.2 is a documentation and command-name consistency maintenance release.

## What changed

- Standardized the Python project identifier and console command as `jlabroc_jsrt_mrmc`, matching the import/module name.
- Updated README, English/Japanese Quick Start guides, and the beginner user guide to use the underscore-form console command consistently.
- Documented the tested Python range as Python 3.10-3.12.
- Added Linux installation guidance for PEP 668 externally managed Python environments, recommending a virtual environment or `pipx`.
- The GitHub repository URL remains unchanged.

## Numerical algorithms

No JLABROC fitting, jackknife pseudo-value, ANOVA, confidence-interval, degrees-of-freedom calculation, validation dataset, numerical reference, or systematic simulation design was changed in this release.

GitHub Actions should be confirmed on the release commit before tagging `v1.0.2`.
