# Example-data provenance

The beginner examples in this folder were selected from files already included in the validated v1.0.1 repository.

| Beginner example | Original location in v1.0.1 | Purpose |
|---|---|---|
| `jlabroc/TestSample1.txt` | `validation/data/jlabroc/Test_R1A_In.txt` | Archived-reference JLABROC validation example |
| `mrmc/TestSample2.txt` | `validation/data/mrmc/RateData_Level2_R5_ver050_50_50_00001.txt` | Archived-reference JSRT-MRMC validation example, matrix format |
| `mrmc/TestSample3.txt` | `tests/data/Test_In_forMRMC_R5_P50_N50_legacy.txt` | Legacy reader-block input compatibility example corresponding to the same 5-reader MRMC data |

The files are duplicated under `examples/` solely to provide simple, stable paths for first-time users. The original validation/test copies remain unchanged.
